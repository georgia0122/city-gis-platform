// 1. 点击"图片"按钮 // 2. 选择图片 // 3. 输入问题或直接发送 // 4. AI 会自动分析图片内容和回答问题

📝 支持的文件格式

图片格式 🖼️

PNG, JPG/JPEG, GIF, WEBP, BMP

自动提取颜色、尺寸、透明度等信息

文档格式 📄

PDF: 智能文本提取（前 5 页）

Word: 段落和表格识别（.docx, .doc）

文本: 自动编码检测（.txt）

单文件最大 10MB，建议使用 5MB 以下
